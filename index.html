Selected casebook

从问题到验证

每个项目都按“构建内容、关键决策、验证证据”展开， 重点说明我真正负责的系统边界与技术取舍。

01 /

MultiModal-QC

Qwen2-VL + QLoRA 工业多模态质检

Read case GitHub
Built
将 MVTec-AD 转换为 1,725 条图文 QA，使用 Qwen2-VL-2B + 4-bit QLoRA 训练，并实现四阶段 Agent Pipeline。
Decision
以 ResNet50、YOLOv8n-cls 为 Baseline，保留分类性能对照，同时输出缺陷类型、位置、严重程度与处置建议。
Verified
测试集 n=173：Accuracy 89.02%、F1 0.893、ROUGE-L 0.249；完成 FastAPI、Gradio、SQLite 推理闭环。

02 /

AIRI Memory Agent

从多源知识到长期记忆与 LoRA 数据飞轮

Read case GitHub
Built
构建“本地即时反应脑 + GBrain 长期记忆脑 + 云端监督增强模型”，接入 Gemma/Ollama、语音、视觉与桌面舞台。
Decision
将事实记忆与模型行为解耦；多源内容先经审核、压缩、冲突检查，再进入本地记忆与 RAG 上下文。
Verified
贯通 Obsidian/Markdown、LLMWiki、Review Workbench、Dream Cycle，并将高质量记忆导出为 LoRA candidate。

03 /

MiniBox

GPT-SoVITS + ESP32-S3 角色语音交互硬件系统

Read case GitHub
Built
利用 UVR5 构建干音数据集并微调 GPT-SoVITS，将语音克隆封装为 FastAPI 异步服务，接入 LLM 与 WebUI。
Decision
由 PC 侧承担 STT/LLM/TTS，ESP32-S3 负责录音与播放；采用标点流式截断和异步合成降低首段语音延迟。
Verified
打通“端侧录音 - PC 推理 - 端侧播放”闭环，实现可嵌入实体机器人、支持角色语音和多轮对话的低成本方案。

04 /

Code Island

面向 AI Coding Agent 的 Windows 状态与权限工具

Read case GitHub
Built
用 WPF/.NET 8 构建 Windows 动态岛，将 Claude Code 与 Cursor 的思考、工具调用、权限请求和完成状态集中展示。
Decision
通过 Hook、Python 脚本与 Named Pipe 解耦 Agent 事件和桌面 UI；高风险工具调用必须由用户显式批准或拒绝。
Verified
覆盖多会话、全局快捷键、全屏避让、CPU/GPU 监测与发布构建，让 AI Coding 过程可观察、可控制。

05 /

Image2 Local Studio

本地 GPT Image 2 工作台与可复用 Prompt Skills

Read case GitHub
Built
把 API 配置、官方尺寸、4K 超分、生成预览和图片墙整合到可一键启动的 Node.js + HTML 本地工作台。
Decision
将中文提示词方法沉淀为可编辑、可复用的 Prompt Skills，使模型调用参数与创作知识分离维护。
Verified
完成“配置 - Skill 选择 - 生成 - 预览 - 保存”的端到端流程，支持本地管理生成记录与作品资产。

Engineering principles

我如何构建 AI 系统

01

先定义边界，再接入模型

明确输入输出、隐私范围、失败路径和人工确认节点，让模型在可控系统中发挥能力。

02

把知识变成可维护资产

通过结构化文档、记忆分层、审核与版本管理，把隐性经验沉淀为可检索、可复用的上下文。

03

用 Baseline 和测试说话

保留传统方法对照、指标与错误样例；工具链则关注状态可观察、行为可验证和结果可复现。
