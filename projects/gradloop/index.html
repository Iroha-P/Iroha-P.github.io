FROM MATERIALS TO NEXT PRACTICE

从资料，到下一步练习。

将课程资料、技术文档与面试场景串起来。让一次问答不止于答案，而是继续走向练习、反馈与复习。

01 / STUDY

学懂，而不只是看过。

从资料检索与带来源的问答开始，再拆成学习计划、练习和错题复习。知识与练习沿用同一条证据链。

02 / INTERVIEW

把回答，变成可练习的反馈。

围绕专业解释与面试表达记录结构化反馈，再进入下一轮练习。评分实验与真实用户效果分开记录。

03 / CONTROL

能继续，也能停下来确认。

用 LangGraph checkpoint 与 interrupt/resume 保存本地工作流状态。计划调整由用户确认，不静默替人做决定。

LOCAL LEARNING LOOP

一次问答，是闭环的开始。

  1. 01

    资料问答

    检索候选片段，将回答限制在可引用的证据范围内。

  2. 02

    计划与练习

    连接学习目标、练习任务与确定性评分基线。

  3. 03

    批改与复习

    保留同一条错题记录，按通过条件进入复习与掌握状态。

  4. 04

    确认与恢复

    有界重试；人工确认计划调整；本地恢复点支持继续执行。
