01 / PROBLEM

为谁解决什么问题

学习资料、问答和练习容易分散在不同工具中，用户需要基于来源理解内容，并知道下一步如何练习。

02 / SOLUTION

把能力组织为使用流程

资料 → 来源问答 → 学习计划 → 练习批改 → 错题复习

用 LangGraph 组织有界工具执行，以 FastAPI/SSE 返回进度；BM25 提供不依赖生成模型的检索基线。计划调整通过人工确认后写入，SQLite 保存学习状态。

03 / DECISIONS

先做什么，如何取舍

先打通知识检索与练习闭环；实时音视频留待接口和模型验收后推进。

先完成可解释的本地学习闭环，再扩展检索和多模态能力。将检索后端、业务状态和生成模型分开，便于替换与排查。

04 / EVIDENCE

已实现什么，证据在哪里

公开 Demo 使用合成资料，不代表真实在线模型推理。历史 Base / LoRA 各 10/10 smoke；固定 5 例评测未获提升，保留 Base。RAGSDK 真实运行与浏览器实时音视频仍待验收。
