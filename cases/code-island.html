Code Island

让 AI Coding 的状态可见、权限可控

Windows 桌面工具

场景拆解 · 产品取舍 · 工程验证

图片为项目界面或展示页，具体运行范围见下方验证说明。

01 用户问题02 产品方案03 关键取舍04 验证证据05 下一步验证
01 / PROBLEM

为谁解决什么问题

多个 AI 编码会话并行时，用户需要快速知道哪个正在执行、哪个等待权限、哪个已经完成。

02 / SOLUTION

把能力组织为使用流程

接收会话事件 → 显示状态 → 提示权限请求 → 用户处理 → 完成提醒

使用 WPF/.NET 8 构建 Windows 动态岛，接入 Claude Code、Cursor 的状态事件，并提供快捷键、全屏避让与资源监测。

03 / DECISIONS

先做什么，如何取舍

优先解决状态可见与权限处理；事件桥接和界面分离，减少对具体助手的耦合。

以事件桥接方式分离状态来源和界面。将权限请求做成明确的用户操作，保留对高风险调用的批准与拒绝。

04 / EVIDENCE

已实现什么，证据在哪里

主页说明多会话、快捷键、监测及发布构建覆盖情况。未报告受控可用性实验，不将产品意图写成已测量的效率提升。

05 / NEXT VALIDATION

下一步如何判断是否有用

权限请求漏看率、状态更新延迟与重复操作次数；效率收益需要任务对照验证。

以上为建议验证方向，不是已经完成的用户研究、A/B 测试或业务增长结果。
