01 / PROBLEM

为谁解决什么问题

工业质检需要的不只是分类标签，还需要把识别结果转成便于人员复核的结构化信息。

02 / SOLUTION

把能力组织为使用流程

输入图像 → 缺陷识别 → 结构化说明 → 人员复核 → 历史记录

使用 Qwen2-VL-2B 与 4-bit QLoRA，保留 ResNet50、YOLOv8n-cls 分类基线，并通过 FastAPI、Gradio 和 SQLite 连接推理与记录。

03 / DECISIONS

先做什么，如何取舍

先保留分类基线并验证缺陷判断，再用多模态输出补充解释与处置建议。

同时保留分类性能对照和结构化解释输出。通过结果呈现与历史记录，让模型能力进入可演示的业务流程。

04 / EVIDENCE

已实现什么，证据在哪里

主页报告测试集 n=173，Accuracy 89.02%、F1 0.893、ROUGE-L 0.249。这些为项目实验指标，不代表工业现场部署效果。

05 / NEXT VALIDATION

下一步如何判断是否有用

按缺陷类别统计漏检与误报、检查解释一致性；真实场景复核时间仍待测量。

以上为建议验证方向，不是已经完成的用户研究、A/B 测试或业务增长结果。
